# ineta-imgs

Imatges de la plantilla de factura d'INETA, S.A. a Holded.

| Fitxer | Mida | On es fa servir |
|---|---|---|
| `logo.png` | 600 px | logo principal (es puja a la ranura Logo de Holded) |
| `mr.png` | 500 px | bloc "Marcas Registradas" de la capçalera |
| `45.png` | 320 px | segell del 45è aniversari |
| `*.svg` | vector | mateixes imatges per a web o impressió gran |

Els PNG porten fons blanc i paleta reduïda: pesen entre 6 i 10 kB, que és el que
convé perquè Holded els baixi de pressa cada cop que genera un PDF.

**No canviïs els noms ni les carpetes.** Les factures ja emeses tornen a
descarregar la imatge cada cop que es regenera el PDF; si es mou un fitxer, es
queden sense.

Origen: reconstruïdes a partir de les factures escanejades de gener de 2026
(59939 i 59941), vectoritzades i adreçades. Si el client envia els originals,
substituir-les aquí mateix mantenint els noms.
